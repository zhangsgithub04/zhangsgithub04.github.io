Learn U-Net by seeing the “U”.

U-Net is a convolutional neural network for dense prediction: instead of assigning one label to a whole image, it predicts a label for every pixel. It became famous for biomedical segmentation, but the same idea appears in satellite imaging, defect detection, matting, restoration, and diffusion models.

The core idea

1 · Encoder

Compress the image

Repeated convolutions and downsampling let the network recognize larger structures. Nearby pixels are combined into higher-level features.

2 · Bottleneck

Understand the scene

The deepest layer has the broadest receptive field. It sees enough context to decide whether a region belongs to the object class.

3 · Decoder + skips

Recover precise borders

Upsampling restores resolution. Skip connections copy high-resolution encoder features into the decoder so boundaries stay sharp.

Why the skip connections matter

Downsampling is useful, but it discards exact location detail. U-Net solves this by concatenating encoder features with decoder features at matching resolutions.

\[\text{decoder input} = \operatorname{concat}(\text{upsampled features},\ \text{encoder skip features})\]

Think of the bottleneck as saying what is present, while skip connections remind the decoder where edges, corners, and textures were.

Typical layer pattern

  1. Double convolution: Conv → activation → Conv → activation.
  2. Downsample: max pooling or strided convolution.
  3. Upsample: transposed convolution, interpolation, or resize-conv.
  4. Final 1×1 convolution: convert features into class logits per pixel.

Modern variants may use batch normalization, residual blocks, attention gates, transformers, or pretrained encoders.

Segmentation output and loss

Binary segmentation

For each pixel, the model outputs a logit. A sigmoid converts that logit into a probability of foreground.

\[\hat y_{i}=\sigma(z_i)=\frac{1}{1+e^{-z_i}}\]

The mask has the same height and width as the input image.

Dice coefficient

Dice measures overlap between prediction and target. It is popular when foreground pixels are rare.

\[\operatorname{Dice}(p,y)=\frac{2\sum_i p_i y_i+\epsilon}{\sum_i p_i+\sum_i y_i+\epsilon}\]

Training often minimizes \(1-\operatorname{Dice}\), binary cross-entropy, or a combination.

Minimal U-Net pseudocode

class UNet(nn.Module):
    def __init__(self, in_channels=1, out_channels=1):
        super().__init__()
        self.enc1 = DoubleConv(in_channels, 64)
        self.enc2 = DoubleConv(64, 128)
        self.enc3 = DoubleConv(128, 256)
        self.pool = nn.MaxPool2d(2)

        self.bottleneck = DoubleConv(256, 512)

        self.up3 = nn.ConvTranspose2d(512, 256, 2, stride=2)
        self.dec3 = DoubleConv(512, 256)  # 256 up + 256 skip
        self.up2 = nn.ConvTranspose2d(256, 128, 2, stride=2)
        self.dec2 = DoubleConv(256, 128)
        self.up1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.dec1 = DoubleConv(128, 64)

        self.out = nn.Conv2d(64, out_channels, kernel_size=1)

    def forward(self, x):
        s1 = self.enc1(x)
        s2 = self.enc2(self.pool(s1))
        s3 = self.enc3(self.pool(s2))
        b = self.bottleneck(self.pool(s3))

        x = self.up3(b)
        x = self.dec3(torch.cat([x, s3], dim=1))
        x = self.up2(x)
        x = self.dec2(torch.cat([x, s2], dim=1))
        x = self.up1(x)
        x = self.dec1(torch.cat([x, s1], dim=1))
        return self.out(x)  # logits, not probabilities
def conv_block(x, filters):
    x = Conv2D(filters, 3, padding="same", activation="relu")(x)
    x = Conv2D(filters, 3, padding="same", activation="relu")(x)
    return x

def unet(input_shape=(256, 256, 1), classes=1):
    inputs = Input(input_shape)

    c1 = conv_block(inputs, 64)
    p1 = MaxPooling2D()(c1)
    c2 = conv_block(p1, 128)
    p2 = MaxPooling2D()(c2)
    c3 = conv_block(p2, 256)
    p3 = MaxPooling2D()(c3)

    b = conv_block(p3, 512)

    u3 = UpSampling2D()(b)
    u3 = Concatenate()([u3, c3])
    c4 = conv_block(u3, 256)
    u2 = UpSampling2D()(c4)
    u2 = Concatenate()([u2, c2])
    c5 = conv_block(u2, 128)
    u1 = UpSampling2D()(c5)
    u1 = Concatenate()([u1, c1])
    c6 = conv_block(u1, 64)

    outputs = Conv2D(classes, 1, activation="sigmoid")(c6)
    return Model(inputs, outputs)

for image, mask in loader:
    logits = model(image)                  # shape: [B, 1, H, W]
    bce = binary_cross_entropy_with_logits(logits, mask)

    prob = sigmoid(logits)
    dice = (2 * (prob * mask).sum() + eps) / (prob.sum() + mask.sum() + eps)
    loss = bce + (1 - dice)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

# Inference

Common practical tips

Patch training

Large images can be trained as smaller crops. At inference, stitch overlapping predictions to avoid boundary artifacts.

Class imbalance

When foreground is tiny, combine Dice, focal loss, weighted BCE, or sampling strategies.

Augmentation

Flips, rotations, elastic deformations, color jitter, blur, and noise help generalization, especially with limited labels.

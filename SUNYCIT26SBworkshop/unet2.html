U-Net · defocus · quantitative phase / image recovery

Recover quantitative images from defocused photos.

The goal is not only to make a prettier image. Quantitative recovery estimates physically meaningful fields: phase φ(x,y), optical path length, thickness, refractive-index contrast, amplitude, or all-in-focus intensity. Defocus provides the measurements; U-Net learns a calibrated inverse map.

What quantitative image recovery means

Recover fields

Not just labels

Output continuous values: phase in radians, optical path length in nanometers, thickness, refractive-index contrast, amplitude, or a deblurred all-in-focus image.

Preserve units

Calibrated scale

A model that gets shapes right but shifts phase scale is not quantitative. Calibration targets, holographic labels, synthetic forward models, or TIE baselines can anchor units.

Measure error

Report numbers

Use MAE/RMSE in physical units, phase-gradient error, SSIM, correlation, frequency response, and bias on known objects.

Physics anchor: defocus encodes phase

Transport of intensity equation

For paraxial propagation, the axial intensity derivative is linked to transverse phase gradients.

dI/dz = -λ/(2π) · div( I · grad(φ) )

This makes through-focus images a natural source for quantitative phase imaging.

Learning view

U-Net learns a direct inverse map from defocused measurements and acquisition metadata.

{φ_hat, A_hat} = fθ(I_-Δz, I_0, I_+Δz, Δz, λ, NA, pixel size)

Pixel size, illumination, numerical aperture, and PSF parameters matter because the target is calibrated recovery.

U-Net design for quantitative recovery

Model choices

  • Input: one defocused image, symmetric stack I-, I0, I+, multi-distance stack, or multi-wavelength stack.
  • Output: one channel for phase, two channels for phase + amplitude, or additional uncertainty channel.
  • Final activation: linear for calibrated regression; tanh only if labels are normalized and later rescaled.
  • Skip connections: retain high-frequency phase edges while decoder uses global context.

Loss function

Loss = L1(s·φ_hat + b, φ) + α·L1(grad φ_hat, grad φ) + β·L1(P(φ_hat,A_hat), I_defocus)

The optional scale s and offset b are useful diagnostics: if they drift, the model may be visually correct but not quantitatively calibrated.

Research design checklist

1. Data

Pair defocused bright-field images with reference phase from off-axis holography, digital holographic microscopy, synthetic optics simulation, calibration samples, or trusted TIE reconstructions. A strong study should include both synthetic phantoms and real samples.

2. Baselines

Compare against TIE, contrast-transfer-function inversion, deconvolution, regularized optimization, U-Net without physics loss, and U-Net with physics consistency.

3. Validation

Hold out specimen types, defocus distances, illumination settings, objectives, and acquisition days. Cross-instrument testing is especially important for quantitative phase recovery.

Failure modes

  • Hallucinated structures when the defocus cue is weak.
  • Correct morphology but wrong phase scale.
  • Domain shift from synthetic to real microscopy.
  • Boundary artifacts from patch-wise inference.
  • Ambiguity between absorption and phase if amplitude is ignored.
  • Overfitting to one defocus distance, objective, illumination aperture, or sample class.

U-Net from defocus

Minimal research pseudocode

# Input: defocus stack [I_minus, I_focus, I_plus]
# Output: quantitative phase map, optionally amplitude and uncertainty
model = UNet(in_channels=3, out_channels=2, final_activation="linear")
phase_amp = model(defocus_stack)
phase_pred = phase_amp[:, 0:1]
amplitude_pred = phase_amp[:, 1:2]
phase_loss = L1(phase_pred, phase_gt)
grad_loss = L1(gradient(phase_pred), gradient(phase_gt))
I_pred = forward_propagate(phase_pred, amplitude_pred, dz, wavelength, pixel_size)
physics_loss = L1(I_pred, I_measured_defocus)
loss = phase_loss + alpha * grad_loss + beta * physics_loss
mae_rad = mean(abs(phase_pred - phase_gt))
rmse_rad = sqrt(mean((phase_pred - phase_gt)**2))
scale, offset = fit_linear(phase_pred, phase_gt)
edge_error = rmse(gradient(phase_pred), gradient(phase_gt))
